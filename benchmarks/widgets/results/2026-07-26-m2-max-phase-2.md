# Ingot UI Build Phase 2 Baseline — 2026-07-26

This is a dated Ingot-only headless core baseline for isolated UI construction paths. It is not a
cross-framework ranking and excludes GPU execution, presentation, native event handling, and application
integration.

## Environment

- Machine: Apple M2 Max, arm64
- OS: macOS 15.6.1
- Drawable contract: 1280×720, scale factor 1
- Collection: 300 warm-up frames, 2,000 measured frames, seven fresh processes per case
- Ingot: workspace revision, Odin `dev-2026-06:285f6d87b`
- Telemetry: `INGOT_UI_TELEMETRY=true`
- Run order: randomized by the suite runner
- Power disclosure: AC, low-power mode off

Changing unique text includes formatting during every measured frame and is 5.5× the stable-unique
build median. Active inputs cost 50% more than inactive inputs in this no-event state. Enabling button
semantics approximately doubles total latency and makes finalization measurable because 100 semantic
nodes are copied into the finalized snapshot.

## Limitations

- Active inputs exercise `input_at(..., active=true)` without injected typing, IME, or selection changes.
- Paint storage is fixed-capacity; `capacity` is overflow evidence, not a forced-growth measurement.
- Telemetry describes one deterministic representative frame per process, not an average over samples.
- The headless text backend models text width and recording cost but not font shaping or GPU rendering.
- Total frame timing encloses frame begin, build, and finalization; it is measured directly rather than
  calculated by adding phase medians.
