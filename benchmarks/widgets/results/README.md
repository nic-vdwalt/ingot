# Benchmark Results

Dated machine-specific reports may be committed here only when their raw JSONL input, manifest,
framework revisions, compiler versions, hardware, display configuration, and power mode are retained.

Large raw runs should live in an external artifact store with a stable checksum and retrieval location.
Do not commit generated `build/`, `cache/`, or Cargo `target/` directories. Invalid nominal samples are
not publishable; capacity-overflow samples belong only in capacity evidence.
