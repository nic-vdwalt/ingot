# Headless Core Widget Results - 2026-07-26

> **Superseded by [2026-07-29-m2-max-core.md](2026-07-29-m2-max-core.md).** This run predates four
> adapter-conformance fixes: the Dear ImGui adapter emitted unpadded labels instead of the pinned
> `Widget %08d` (doing less per-label work than Ingot and egui), all adapters formatted
> frame-invariant labels inside the timed region, the churn workload compared Ingot's full-rotation
> churn against a no-op in the other two adapters, and table cell indexing diverged. The numbers
> below are retained for provenance, not comparison.

These results are a dated local measurement, not a universal framework ranking. They measure headless
CPU work for equivalent fixed-geometry benchmark adapters. They do not measure native rendering, GPU
time, presentation, memory, startup, idle power, or the complete application integrations.

## Environment

- Machine: Apple M2 Max, arm64
- OS: macOS 15.6.1
- Drawable contract: 1280×720, scale factor 1
- Collection: 300 warm-up frames, 2,000 measured frames, seven fresh processes per case
- Ingot: workspace revision, Odin `dev-2026-06:285f6d87b`
- Dear ImGui: `5d4126876bc10396d4c6511853ff10964414c776`
- egui: `f2ab57d6987a9b7984f0637cc4d9f2fd173c507c`, Rust 1.90.0
- Run order: randomized by the suite runner
- Validation: 1,008 result records accepted; nominal dropped-output records rejected

Display refresh and power-mode metadata were not set for this run. That omission does not affect the
headless CPU contract directly, but it prevents this run from serving as complete native-system evidence.

## What This Establishes

- Ingot is competitive with Dear ImGui for this suite's headless fixed-geometry core work.
- Ingot led the representative repeated-label, mixed-form, and virtual-list cases.
- Dear ImGui led the representative button, full-list, table-like, and churn cases.
- egui took substantially more core CPU time in these adapters, but it also offers a richer layout and
  retained integration model; these numbers do not isolate the cost of individual architectural features.
- Virtualization kept all three frameworks nearly independent of the one-million-row logical data size
  because only 44 rows were submitted.

## Limits

The benchmark adapters are intentionally equivalent rather than idiomatic showcase applications. Dear
ImGui has no core accessibility implementation, and the egui accessibility case does not include an
`eframe`/AccessKit host, so accessibility rows are not a complete feature-parity comparison. Paint output
also differs by framework, and headless finalization boundaries are not identical enough to combine into
one cross-framework score.

Re-run the checked-in suite before making release claims on different hardware or revisions. Raw data for
this local run was generated at `/tmp/widget-results.jsonl` and was not committed because repository
policy requires durable artifact hosting and checksums for bulky raw runs.
